# GelaLand - сайт эко-домов на Волге (Углич)

Статический сайт без сервера. Хостинг - GitHub Pages.

- `index.html` - сайт. Весь контент берёт из `data/content.json`, занятые даты - из `data/bookings.json`.
- `admin.html` - панель владельца: цены (будни/выходные), сезоны, особая цена на день, закрытые даты, тексты, услуги, отзывы, фото. Сохраняет `data/content.json` через GitHub API, нужен fine-grained token с правом Contents: write на этот репозиторий.
- `scripts/sync_bookings.py` + workflow `sync-bookings.yml` - раз в час тянет iCal-ссылки домов (поле `icalUrl` в админке) и пишет занятые ночи в `data/bookings.json`.
- `img/` - фотографии.

Правила цен: базовая цена будни/выходные, сезон перекрывает базовую на свой период, особая цена на дату перекрывает всё. Выходными считаются ночи пт и сб (`site.weekendNights`).
